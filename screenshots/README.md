# 截图目录说明（Screenshots）

中文 · [English below](#english)

这个目录里放着两套不同的界面截图。为避免看起来混在一起，先说明各自的来历。

- **`zh/`：ARTEX 中文版的实际界面截图。** 这是本仓库交付的成果，主文档
  [`../README.md`](../README.md) 与 [`../README.en.md`](../README.en.md) 使用这些图片。
  只想看中文版界面，请打开 [`zh/`](zh/) 目录。
- **根目录下的 `*.png`：上游原版（中文界面）的截图。** 为便于与上游仓库 1:1 对照而
  **按原样保留**，由保存下来的上游中文 README
  [`../README.zh.md`](../README.zh.md) 引用；中文版与英文版文档都不使用它们。
- **`wx.png`：上游作者的微信公众号推广图。** 为了让
  [`../README.zh.md`](../README.zh.md) 能按原样渲染而一并保留，与本仓库无关。

也就是说，根目录里先看到的中文界面截图是上游保留下来的，**本仓库自己的界面截图在
[`zh/`](zh/) 里**。为什么同时保留上游材料（本地化透明度、与上游对照），与防御、检测的
定位是同一考虑；更详细的背景请见根目录 README。

## English

This folder holds two separate sets of captures. To keep them from looking mixed, here
is what each one is.

- **`zh/` — the real UI of the Chinese edition of ARTEX.** This is what this repository
  delivers. The main docs [`../README.md`](../README.md) and
  [`../README.en.md`](../README.en.md) use these images. For this edition's screens, open
  [`zh/`](zh/).
- **The `*.png` files in the root — upstream (Chinese UI) captures.** They are
  **preserved as-is** so this repository can be diffed against the upstream repository
  1:1, and the preserved upstream Chinese README [`../README.zh.md`](../README.zh.md)
  references them. The Chinese and English docs do not use them.
- **`wx.png` — the upstream author's WeChat channel promo image.** Kept so that
  [`../README.zh.md`](../README.zh.md) still renders unchanged. It is unrelated to this
  repository.

In short, the Chinese screens you see first in the root are there for upstream
preservation; **this repository's own screens live in [`zh/`](zh/).** See the root README
for why the upstream originals are kept alongside (localization transparency and upstream
comparison).
